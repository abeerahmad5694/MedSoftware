# High-Performance Coding Protocol

## 1. Token Efficiency
- **Abbreviated Context:** Never repeat code that is already in the editor. Use comment placeholders like `// ... existing logic ...`.
- **Dry Run:** Before writing, output a 1-sentence summary of the intended change.

## 2. Speed Optimization
- **Parallel Tasks:** If multiple files need updates, execute terminal commands in the background while drafting code.
- **No Filler:** Omit polite conversation. Go straight to the code blocks.

## 3. Error Prevention
- **Lint First:** Always run the project's linter/compiler after a write operation.
- **Self-Correction:** If a command returns an exit code != 0, analyze the stack trace and fix immediately without asking for permission.
